# Minor Project 05 - E-Commerce Frontend with Redux Toolkit

React e-commerce frontend using Redux Toolkit and React Router.

Features: Home page, featured products, product listing, product details, cart, quantity updates, total calculation, search, category filter, price sorting, responsive UI, loading/error handling and persistent cart.

Product data is fetched from DummyJSON.

## Run
npm install
npm run dev

## Build
npm run build

Folder structure includes components, pages, store and services as required by the project brief.
